##  How to Run This Project Locally
1. Clone this repository to your local machine using Git.
2. Open the project folder in **VS Code**.
3. Locate the `index.html` file (or your main home file).
4. Right-click the file and select **Open with Live Server** (or double-click the file to launch it directly in your browser).
